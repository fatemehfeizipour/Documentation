The three types of IAM policies
	
	AWS Managed Policy → Created and maintained by AWS.

	Customer Managed Policy → Created by you, reusable, and best for custom permissions.

	Inline Policy → Embedded in one user, group, or role; not reusable.



A simple way to remember it is:

	AWS Managed = AWS writes it.

	Customer Managed = You write it once and reuse it.

	Inline = You write it once for one identity only.
